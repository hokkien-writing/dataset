# 中英文與羅馬字標點轉換設計

## 目標

建立可重用、可雙向轉換且具冪等性的標點工具。007 詞典由 wikitext 產生 Markdown 時，漢字內容使用中文標點，PUJ 與英文內容使用羅馬標點；同時依相同規則整理 `books/（合併校對&修正讀音）斐姑娘詞典.csv`，保留原有列序、表頭與非目標欄位。

## 轉換規則

中文與羅馬標點的基本映射如下：

| 中文 | 羅馬 |
| --- | --- |
| `，` | `,` |
| `。` | `.` |
| `；` | `;` |
| `：` | `:` |
| `！` | `!` |
| `？` | `?` |
| `（` `）` | `(` `)` |
| `“` `”` | `"` `"` |
| `‘` `’` | `'` `'` |

羅馬模式移除標點前的多餘空格，並在逗號、分號、冒號、句號、問號及驚嘆號後需要時補一個空格；行尾、右括號或右引號前不補空格。中文模式移除中文標點兩側因轉換產生的不必要空格。

詞內 ASCII 或彎曲撇號視為 apostrophe，不視為引號。`don't` 保持不變，`don‘t` 與 `don’t` 正規化為 `don't`。單引號只有在可判定為成對引用符號時才參與引號轉換。

## 架構

新增一個無檔案 I/O 的標點模組，公開：

- `to_roman_punctuation(text)`：將中文標點轉為羅馬標點並整理羅馬排版空格。
- `to_chinese_punctuation(text)`：將羅馬標點轉為中文標點並整理中文排版空格。

另提供薄層 CLI，支援：

- `--mode roman|chinese`：處理單一語系的純文本檔。
- CSV 欄位策略：對指定 CSV 依欄位選擇轉換方向。

核心函式不感知 CSV 或 Markdown，方便獨立測試與其他書籍重用。

## Markdown 整合

在 007 專用 `postprocess` 的結構整理完成後、最終輸出前執行標點正規化。只處理既有詞條結構中的語意片段：

- `**字目**`：中文模式。
- 詞條中的斜體 PUJ：羅馬模式。
- 破折號後的英文釋義：羅馬模式。

頁碼標記、標題、水平線及 Markdown 標記本身不參與轉換。無法識別為 007 詞條結構的自由文本保持原樣，避免以字符鄰近關係猜測語言。

## CSV 整理

對 `books/（合併校對&修正讀音）斐姑娘詞典.csv` 使用固定欄位策略：

- `字目`、`词条`：中文模式。
- `读音`、`释义`：羅馬模式。
- `字段1`、`字段2`、`页码` 及任何額外欄位：保持原值。

以 `csv.DictReader`／`csv.DictWriter` 和 UTF-8 讀寫。輸出維持原表頭、列順序與列數。原地更新先寫同目錄臨時檔，再以原子替換完成；操作前計算各欄變更數，操作後再次讀取並驗證結構。

## CLI 與錯誤處理

CLI 對不存在的輸入、未知模式、CSV 缺少必要欄位或輸入輸出路徑衝突給出非零退出狀態。原地 CSV 模式只在完整轉換與驗證成功後替換來源；失敗時來源保持不變。

CLI 輸出摘要包含總列數、各欄變更數及總變更列數，便於人工核對和後續稽核。

## 測試與驗收

單元測試覆蓋：

- 所有基本標點的雙向映射。
- 括號、成對單雙引號及引號內標點。
- `don't`、`don‘t`、`don’t` 等詞內撇號案例。
- 中英文標點周圍空格規則。
- 兩個方向重複執行的冪等性。
- 007 頭詞、PUJ 例句和英文釋義的 Markdown 結構保持。
- CSV 欄位策略、原順序、非目標欄與列數保持。

實際資料驗收包括：執行相關 `unittest`、再生 007 Markdown、驗證頁碼標記、解析詞條數不減少、掃描 PUJ／英文區段殘留的中文目標標點，以及確認 CSV 的列數與主鍵欄位順序不變。

## 相容性與回退

既有 wikitext 解析與詞條重排邏輯不變，只新增最終語意片段正規化。工具函式預設不執行檔案寫入。CSV 修改可由 Git 差異完整檢視與回退；轉換具冪等性，重跑不應產生新差異。

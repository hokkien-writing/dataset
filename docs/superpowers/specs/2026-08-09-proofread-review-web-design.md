# 007 人工校订网页设计

## 目标

构建一个仅在本机运行的审校网页，让使用者对 131 个无法安全自动裁定的唯一词条（共 133 个问题）查看原书、选择提案、手工修改最终值，并导出可验证、可逆的 JSON 决策文件。

## 范围

第一版只包含：93 笔 reading/gloss cross-type 冲突、27 笔空键结构修正、1 笔既有键冲突、12 笔截断释义。其中 2 个截断问题与 cross-type 冲突发生在同一词条，因此界面是 131 个唯一词条、133 个问题。其余有明确 `Proofread_*` 裁定的项目不进入网页。

网页不直接修改 CSV、007 修正表或 Markdown。回写属于后续独立步骤。

## 架构

使用 Python 3.10+ 标准库建立本机 HTTP 服务，复用系统 Poppler 的 `pdftoppm` 按需渲染并缓存 PDF 页面。前端使用原生 HTML、CSS 与 JavaScript，不新增 Node 工具链或第三方运行时依赖。

服务读取生成后的 `review_data.json`。浏览器用稳定记录 ID 将草稿保存在 `localStorage`，并导出带资料版本与原值摘要的 JSON。服务只绑定 `127.0.0.1`。

## 文件职责

- `scripts/proofread_review/build_data.py`：从权威校对 CSV、`actions2.json` 与 007 资料生成 133 笔审校数据。
- `scripts/proofread_review/models.py`：稳定 ID、输入验证、资料版本与决策导出验证。
- `scripts/proofread_review/server.py`：静态文件、资料 API、健康检查及 PDF 页面渲染缓存。
- `scripts/proofread_review/static/`：密集双栏审校界面。
- `scripts/tests/test_proofread_review.py`：资料范围、稳定 ID、页码偏移、路径安全与决策验证测试。
- `scripts/run_proofread_review.py`：最小启动入口。

## 操作流程

页面进入第一笔未决定项目。顶部显示进度、冲突类型、词条页码及 PDF 页码。左侧显示原书页面；游标位于原书区时，鼠标滚轮以游标位置为中心缩放，拖曳平移，双击恢复适合宽度，并可前后翻页。

右侧按字段并排显示当前值、人工提案与可编辑最终值。使用者可逐栏选择采用提案或保留现值，选择后仍可编辑。记录可标为确认或稍后决定；确认后进入下一笔。

提供状态、冲突类型与页码筛选，以及记录跳转。快捷键在文本输入获得焦点时停用。

## 保存与导出

每次选择、编辑、备注或状态变化都会写入 `localStorage`。导出 JSON 包含 schema version、data version、导出时间、记录稳定 ID、原值摘要、决定、最终字段值及备注。

只有状态为 `accepted` 的记录属于可回写集合。`deferred` 与未决定记录仍保留在导出档，但不得被回写器应用。资料版本或原值摘要不符时，后续回写必须拒绝该记录。

## 错误处理

- PDF 不存在、页码超界或 Poppler 不可用时，服务回传明确错误；右侧审校仍可继续使用。
- PDF 页面渲染采用固定参数与缓存键，失败不产生半成品缓存。
- 不接受 `..`、绝对路径或任意文件读取请求。
- 输入资料缺少稳定 ID、冲突类型、页码或必要字段时，启动失败并列出记录。
- 浏览器储存空间或 JSON 导出失败时显示持续可见错误，不把记录误标为已保存。

## 验收

- 数据集恰为 131 个唯一词条、133 个问题且各稳定 ID 唯一。
- 词典页码 32 对应 PDF 页 56，所有页码使用 `+24`。
- 原书滚轮缩放、游标中心定位、拖曳、双击复位正常。
- 选择后可继续修改最终值，刷新页面不会丢失。
- 筛选、跳转、稍后决定、确认并下一条可用。
- 导出 JSON 可重新导入，且保留决定、最终值与备注。
- 服务只绑定本机并阻止路径穿越。
- 131 笔输入、浏览器状态与词典来源均不会被网页直接改写。
